# アイコン差し替え

このフォルダに以下のPNG画像を配置すると、アプリ上のテキストボタンに画像が追加表示されます。
画像がなくてもアプリは動作し、テキストがフォールバックとして表示されます。

- chaos-true.png
- chaos-false.png
- chaos-fire.png
- chaos-water.png
- exdeath-true.png
- exdeath-false.png
- exdeath-thunder.png
- exdeath-water.png
- exdeath-acceleration.png
- gaze.png
- job-whm.png（白魔道士）
- job-sch.png（学者）

ヒーラー加速度モードでは、`job-whm.png` / `job-sch.png` をGC入力画面と処理内容画面の両方で使用します。画像がない場合は白 / 学の文字のみ表示されます。

推奨：正方形PNG、背景透過。例：256×256px。
