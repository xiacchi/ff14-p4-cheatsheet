# FF14 絶妖星乱舞 P4 カンペアプリ

絶妖星乱舞のP4、こんなの覚えてられるか！！！って人向けのカンペです。

## 画面遷移

1. GC1入力画面
2. GC2入力画面
3. 処理内容画面
4. リセットでGC1入力画面へ戻る

## GC2の自動補完

入力回数を減らすため、GC1から一意に決まる項目はGC2で自動補完します。

- カオス：GC1が炎ならGC2は水、GC1が水ならGC2は炎
- エクスデス個人デバフ：GC1が雷/水ならGC2は加速度を自動ON
- エクスデス個人デバフ：GC1が加速度ならGC2の加速度を無効化し、雷/水の2択だけ残す

GC2のカオス真偽・エクスデス真偽は自動補完しません。また、自動補完だけではGC2タイマーは開始せず、GC2で最初に手動入力した時点からカウントを開始します。

## ヒーラー加速度モード

設定の `ヒーラー加速度モード` をONにすると、エクスデスの入力欄に `白` / `学` の加速度記録ボタンを追加します。既定値はOFFです。

- GC1では白・学をそれぞれ独立してON/OFFできる
- 加速度爆弾は全員がGC1またはGC2のどちらか一方で1回受けるため、GC2は各ヒーラーについてGC1の反対を自動設定する
- 例：GC1で白のみON → GC2は学のみON
- GC1で白・学の両方ON → GC2は両方OFF
- GC1で両方OFF → GC2は白・学の両方ON
- 処理内容では白・学それぞれについて、加速度がGC1/GC2のどちらかと `止まる` / `動く` を表示する

このモードの白・学ボタンをGC1で最初に操作した場合も、通常の手動入力と同じくGC1タイマーを開始します。

## 設定

画面右上の歯車ボタンから設定を開きます。

初期値：

| 設定 | 既定値 |
|---|---:|
| GC1 自動切替 | 15秒 |
| GC2 自動切替 | 15秒 |
| 未操作で自動リセット | ON |
| 未操作リセット時間 | 300秒 |
| 画面スリープ防止 | ON |
| スリープ防止時間 | 30分 |
| ヒーラー加速度モード | OFF |

GC1 / GC2の設定可能範囲は1～60秒、未操作リセットは30～3600秒、スリープ防止時間は5～240分です。

## 最終操作からの経過時間

共通ヘッダー右上に `操作なし: X秒` と表示します。

- タップ / クリック相当の `pointerdown` で0秒に戻る
- 未操作自動リセットがONの場合、設定時間に到達するとGC1初期状態へ戻ります

## 画面スリープ防止

対応ブラウザでは Screen Wake Lock API を使い、最後の操作から設定時間だけ画面の自動消灯を抑止します。既定値は30分です。

## マジックチャージ記録

処理内容画面の下部に、GC判定とは独立したマジックチャージ用の簡易メモがあります。

- `直線`：既定は `踏まない`。タップで `踏む`、再タップで `踏まない`
- `扇`：既定は `踏まない`。タップで `踏む`、再タップで `踏まない`

## 注意

- このアプリは早/遅を判定しません。ゲーム内のデバフ残り時間を確認してください。
- 入力不足の状態で確定した場合は、結果画面で該当箇所を `未入力` と表示します。
- 実戦投入前に録画済み動画などで設定時間とUIを確認してください。
