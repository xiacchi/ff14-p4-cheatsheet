# FF14 絶妖星乱舞 P4 カンペアプリ

絶妖星乱舞のP4、こんなの覚えてられるか！！！って人向けのカンペです。

## 画面遷移

1. GC1入力画面
2. GC2入力画面
3. 処理内容画面
4. リセットでGC1入力画面へ戻る


## GC2の自動補完

入力回数を減らすため、GC1から一意に決まる項目はGC2で自動補完します。

- カオス：GC1が炎ならGC2は水、GC1が水ならGC2は炎
- エクスデス個人デバフ：GC1が雷/水ならGC2は加速度を自動ON
- エクスデス個人デバフ：GC1が加速度ならGC2の加速度を無効化し、雷/水の2択だけ残す

GC2のカオス真偽・エクスデス真偽は自動補完しません。また、自動補完だけではGC2タイマーは開始せず、GC2で最初に手動入力した時点からカウントを開始します。

## 設定

画面右上の歯車ボタンから設定を開きます。

初期値：

| 設定 | 既定値 |
|---|---:|
| GC1 自動切替 | 20秒 |
| GC2 自動切替 | 20秒 |
| 未操作で自動リセット | ON |
| 未操作リセット時間 | 300秒 |

GC1 / GC2の設定可能範囲は1～60秒、未操作リセットは30～3600秒です。

## 最終操作からの経過時間

共通ヘッダー右上に `操作なし: X秒` と表示します。

- タップ / クリック相当の `pointerdown` で0秒に戻る
- 未操作自動リセットがONの場合、設定時間に到達するとGC1初期状態へ戻ります

## マジックチャージ記録

処理内容画面の下部に、GC判定とは独立したマジックチャージ用の簡易メモ＋デコード欄があります。

- `直線`：既定は `踏まない`。タップで `踏む`、再タップで `踏まない`
- `扇`：既定は `踏まない`。タップで `踏む`、再タップで `踏まない`

| 直線 | 扇 | 真 | 偽 |
|---|---|---|---|
| 踏まない | 踏まない | 全部踏まない | 全部踏む |
| 踏む | 踏まない | 直線踏む | 扇踏む |
| 踏まない | 踏む | 扇踏む | 直線踏む |
| 踏む | 踏む | 全部踏む | 全部踏まない |

## 注意

- このアプリは早/遅を判定しません。ゲーム内のデバフ残り時間を確認してください。
- 入力不足の状態で確定した場合は、結果画面で該当箇所を `未入力` と表示します。
- 実戦投入前に録画済み動画などで設定時間とUIを確認してください。
